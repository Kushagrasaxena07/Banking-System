# Banking System in Python

This project is a simple banking system implemented using Python and Object-Oriented Programming.

## Features
- Add Customer
- Create Savings Account
- Create Checking Account
- Deposit Money
- Withdraw Money
- Apply Interest
- Display Customers
- Display Accounts

## Technologies Used
- Python
- JSON (for data storage)
- OOP Concepts

## How to Run

1. Clone the repository

git clone https://github.com/yourusername/banking-system-python.git

2. Run the program

python banking_system.py
